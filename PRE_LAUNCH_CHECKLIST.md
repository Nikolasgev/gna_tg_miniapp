## 📋 Конфигурация для production

### Переменные окружения (.env)
```bash
# Database
DATABASE_URL=postgresql+asyncpg://user:password@host:5432/dbname

# Security
SECRET_KEY=<сгенерировать надежный ключ>
ADMIN_PASSWORD=<надежный пароль>

# Telegram
TELEGRAM_BOT_TOKEN=<токен бота>

# Payment
YOOKASSA_SHOP_ID=<ID магазина>
YOOKASSA_SECRET_KEY=<секретный ключ>
YOOKASSA_WEBHOOK_SECRET=<секрет для webhook>

# Delivery
YANDEX_DELIVERY_TOKEN=<токен Яндекс Доставки>
PICKUP_ADDRESS_FULLNAME=<адрес отправления>
PICKUP_ADDRESS_COORDINATES=[37.6000, 55.8000]

# Environment
ENVIRONMENT=production

# CORS (только нужные домены)
CORS_ORIGINS=["https://your-telegram-miniapp.com", "https://your-admin-panel.com"]

# Monitoring (опционально)
SENTRY_DSN=<DSN для Sentry>
```

## 🚨 План действий при проблемах

1. **Проблемы с платежами:**
   - Проверить логи YooKassa
   - Проверить webhook'и
   - Связаться с поддержкой YooKassa

2. **Проблемы с доставкой:**
   - Проверить интеграцию с Яндекс Доставкой
   - Проверить адрес отправления

3. **Проблемы с БД:**
   - Проверить подключение
   - Восстановить из бэкапа при необходимости

4. **Проблемы с производительностью:**
   - Проверить логи
   - Оптимизировать запросы
   - Масштабировать инфраструктуру
