# Презентация предзащиты ВКР

## Файлы

- **predefense_slides.html** — презентация в одном HTML-файле (Reveal.js + Mermaid). Откройте в браузере для показа.

## Как использовать

1. Откройте `predefense_slides.html` в браузере (Chrome, Firefox, Edge).
2. Управление: стрелки влево/вправо или клик по слайду, полноэкранный режим — F.
3. Печать в PDF: в браузере «Печать» → «Сохранить как PDF» (или используйте режим печати Reveal.js: добавьте `?print-pdf` к URL и затем печать).

## Содержание слайдов

| № | Тема | Соответствие требованиям |
|---|------|---------------------------|
| 1 | Титульный лист | Учебное заведение, специальность, ФИО, руководитель, дата |
| 2 | Введение, предметная область и проблемная зона | Подсистемы, текущие процессы, диаграмма проблемы |
| 3 | Цель, постановка задачи | Цель, список задач |
| 4 | Актуальность | Таблица сравнения с аналогами, вывод |
| 5 | Требования к разработке | Функциональная схема: роли и функции |
| 6 | Описание входных данных | Таблица: логическое/физическое название, тип, размер, ограничения |
| 7 | Платформы и технологии | Таблица: вид приложения, платформа, технологии, библиотеки, обоснование |
| 8 | Архитектура программного продукта | Схема: Frontend, Backend, БД, внешние сервисы |
| 9 | Структурная схема | Схема модулей backend и frontend |
| 10 | Описание элементов структурной схемы | Таблица названий и описаний модулей |
| 11 | Демонстрация ПП | Ключевые функции, рекомендация по видео |
| 12 | Завершающий слайд | Ссылка на ПЗ |

## Ссылки на пояснительную записку

На каждом слайде внизу указана ссылка на раздел пояснительной записки (гл. 1.1, 1.2, 1.3 и т.д.) для детального ознакомления.

## Диаграммы

Все диаграммы заданы в коде (Mermaid) внутри HTML — их можно править прямо в файле, они пересчитаются при перезагрузке страницы. Исходники диаграмм архитектуры также лежат в `presentation_diagrams/*.mmd`.
