# Лендинг: EmailJS и проверка формы

## Локально

1. Скопируйте `landing/.env.example` в `landing/.env`.
2. Заполните переменные:
   - `VITE_EMAILJS_PUBLIC_KEY` — публичный ключ из [EmailJS](https://www.emailjs.com/) (раздел Account → API Keys).
   - При использовании отправки через EmailJS SDK также задайте `VITE_EMAILJS_SERVICE_ID` и `VITE_EMAILJS_TEMPLATE_ID` (раскомментируйте строки в `.env.example` и подставьте значения из EmailJS Dashboard).
3. Перезапустите dev-сервер (`npm run dev`), чтобы Vite подхватил переменные.

Без ключей форма может открывать почтовый клиент (`mailto`) — это ожидаемый fallback в коде контактной формы.

## Продакшен

1. Задайте те же переменные в настройках хостинга (Vercel / Netlify / и т.д.) для сборки Vite.
2. После деплоя откройте страницу с формой, отправьте тестовое сообщение и убедитесь, что письмо приходит на целевой ящик (или что срабатывает нужный сценарий EmailJS).

## Lighthouse и a11y

Периодический прогон Lighthouse / проверка доступности в Chrome DevTools — по желанию, отдельно от основного пайплайна.
